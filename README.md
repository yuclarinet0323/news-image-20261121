"The World Today" is a one-image newspaper front page summing up the world news of Saturday 21 November 2026, drawn entirely by a Python program (standard library only, hand-rolled PNG encoder and bitmap font, fully deterministic). The lead story is Russia's overnight barrage of 400+ drones and 110 missiles on Ukraine, with missiles landing in Poland; inside panels cover the Trump-Xi-Putin three-way summit in Shenzhen, the ICJ ruling that Myanmar committed genocide against the Rohingya, the AI stock sell-off pushing Wall Street into correction, stalled Iran talks amid Hormuz attacks, and COP31 running into overtime in Antalya, plus a ticker with the pancreatic-cancer pill breakthrough, BepiColombo's arrival at Mercury, the Peru earthquake and the UK-EU reset deals.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png (1024x1024, byte-identical on every run)
```
